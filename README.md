# The Last Argument

The Last Argument is a timed, scenario-based AI persuasion game. Each scenario gives the player a different objective, an AI character with its own personality and priorities, a limited set of evidence, and hidden facts that can be uncovered through careful questioning.

Players can argue, investigate, or teach the AI while managing trust, suspicion, limited turns, and a running clock. Each conversation can lead to different success, partial-success, or failure outcomes.

The current scenarios include a failing airlock, a murder investigation, and a highly literal maintenance AI attempting to relocate a station cat.
